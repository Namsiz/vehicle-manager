# 我的小摩托

骑上我的小摩托，一路向北...

## 项目说明
这是一个个人车辆管理应用，用于管理你的小摩托。

## 功能特点
- 车辆信息管理
- 状态跟踪
- 简洁现代的UI设计

## 技术栈
- Flutter
- Material 3 设计风格
- 跨平台支持

## 开发状态
- 初始版本
- 基础车辆管理功能已完成

## 许可证
MIT License

## 如何使用
1. 克隆仓库
2. 运行 `flutter pub get`
3. 运行 `flutter build apk --release`
4. 安装生成的APK文件
